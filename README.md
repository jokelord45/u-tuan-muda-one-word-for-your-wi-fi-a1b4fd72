A make.fun bounty entry: a program that picks a single word describing your Wi-Fi — funny and true about bad home Wi-Fi — and writes it to `/output/entry.txt`.

The program scores a pool of candidate words against the judge's brief (on-subject fit, instant laugh, truth, freshness, instant clarity), penalises the clichés every entrant reaches for first, and writes the winner. The winning word is **Ghosting**: the signal is there for the call, then gone mid-sentence — like a bad date.

## Run

```sh
node main.ts
```

It prints the scored candidate table, then writes the winning word to `/output/entry.txt`.
